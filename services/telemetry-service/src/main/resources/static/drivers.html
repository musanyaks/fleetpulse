Drivers

Module on the roadmap — telemetry carries no driver identity yet. The vehicle-simulator and ingestion schema will gain a driverId field, and driver-service will own assignment + scoring.

Planned: Driver Scoring

DriverScore = 100
  − speedingPenalty
  − harshBrakingPenalty     (deceleration > threshold)
  − harshAccelerationPenalty
  − excessiveIdlingPenalty  (engine ON, speed = 0, > N min)
  − unauthorizedRoutePenalty

Computed per trip from telemetry.raw; published to driver.events and surfaced here.

Data sources it will consume

• Kafka telemetry.raw (speed deltas → harsh events)

• Kafka alerts (per-driver attribution)

• PostgreSQL drivers + assignments tables (driver-service, Spring Data JPA)

• Geofence events for route compliance
